This is my second project, and it's designed to be more polished than my previous one. Like before, I built this as a Single Page Application (SPA) using React and Vite, but this time I incorporated TypeScript for some components and helper functions. The site highlights key events that have shaped humanity.

To get started, you can either create a new account or log in with the predefined credentials (user: "peter@abv.bg", password: "123456"). Once logged in, you can create games and add comments. If you're the creator of a game or comment, you have the ability to edit or delete them. However, if you're not the creator, you'll only be able to view them.

This project demonstrates key concepts from React, along with HTML and CSS. I hope you enjoy exploring it!

Тo start the project run the following sequence:

Open Integrated Terminal in client folder and run the following commands : "npm i vite" ,then "npm run dev"

Open Integrated Terminal in server folder and run the following commands : "node server.js"
